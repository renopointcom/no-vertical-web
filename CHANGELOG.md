# Changelog

Toutes les modifications notables de ce projet sont documentées ici.
Format basé sur [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/).

## [1.0.0] — 2026-05-25

### Ajouté
- Première version publique.
- Détection par ratio (hauteur/largeur) et seuil de largeur.
- Combinaison des conditions en `AND` ou `OR`.
- Message HTML configurable.
- Couleurs de fond et de texte personnalisables.
- Image/logo optionnel.
- CSS personnalisé.
- Exclusions par sélecteurs CSS.
- Signature CTRL+ALT+R en console.
- Manifeste par défaut affiché sans configuration.

### Distribution
- GitHub Pages avec domaine personnalisé : nvw.ctrlaltr.org.
- CDN jsDelivr (versionné, immutable, compatible SRI).
- Téléchargement direct pour auto-hébergement.
